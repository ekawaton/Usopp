# Yulgang monitor

เมื่อผู้ใช้ถามว่าเกม "ยังปกติมั้ย" / "แคปจอ" / "เช็กเกม":
1. รัน `powershell -ExecutionPolicy Bypass -File snap.ps1`
2. อ่านไฟล์ `shot.png` แล้วรายงานเป็นภาษาไทยสั้นๆ: HP/MP, เลเวล, ข้อความระบบ (เงิน/ยา), มอนรอบตัว, ระบบออโต้ทำงานอยู่ไหม, จำนวนยาที่เหลือ
3. ถ้าแคปไม่ได้ (จอดำ/ล็อก) ให้รายงานจากผลบรรทัด "YGOnline running / NOT running" แทน

ห้ามส่งคีย์บอร์ด/เมาส์หรือสั่งอะไรในเกม — ดูอย่างเดียว
